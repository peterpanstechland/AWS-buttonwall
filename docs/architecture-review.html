AI 视觉识别		S3 ObjectCreated 触发 Lambda；由 Lambda 调用 Rekognition 并写 DynamoDB。需配置事件过滤、资源策略、幂等与表键。官方依据 1 官方依据 2 官方依据 3
M03_IOT
智能物联网		设备经 MQTT 向 IoT Core 发布，规则调用 Lambda 写表；需要设备证书、主题权限及规则调用权限。官方依据 1 官方依据 2
M04_AGENT
生成式智能体		AgentCore Runtime 托管的自定义代码调用 Bedrock。可选 DynamoDB 是应用自建会话存储，不等同 AgentCore Memory；需校验会话标识、IAM 及同步调用超时。官方依据 1 官方依据 2 官方依据 3
M05_SERVERLESS_WEB
无服务器 Web		CloudFront 缓存未命中才向 S3 回源；浏览器独立调用 API。可选 Cognito 用户池授权器只保护配置了授权的 API 方法，不保护静态页面。官方依据 1 官方依据 2 官方依据 3 官方依据 4
M06_CLASSIC_WEB
经典云计算 Web		EC2 单实例应用加独立静态资源 CDN；未提供负载均衡或高可用。应用日志需要 CloudWatch Agent 或应用主动上报，不能认为默认自动采集。官方依据 1 官方依据 2 官方依据 3
M07_EVENT_DRIVEN
事件驱动处理		Lambda 事件源映射轮询 SQS 并批量调用消费者；至少一次投递，需要幂等、可见性超时、重试、死信队列和部分批次失败处理。结果已保存不表示客户端已收到通知。官方依据 1 官方依据 2 官方依据 3
M08_ML
机器学习推理		S3 存放已训练模型制品，部署后才有 SageMaker 实时端点；Lambda 调用 InvokeEndpoint。部署角色、镜像及端点就绪为前提，本图不包含训练流程。官方依据 1 官方依据 2 官方依据 3
M09_PROTECTED_WEB
带认证 API 的 Web		静态页面可公开访问；Cognito 登录获取令牌，API Gateway 用户池授权器验证访问 API 的令牌。不是整个网站的统一访问保护。官方依据 1 官方依据 2 官方依据 3 官方依据 4
M10_IOT_DIRECT
设备数据直存		IoT 规则动作直接写 DynamoDB；需配置规则 SQL、表键映射、数据类型和 IAM 角色。官方依据 1
M11_ASYNC_API
异步任务入口		API Gateway 使用 AWS 服务集成发送 SQS 消息。成功只表示入队，不表示业务完成；本图未包含消费者、进度查询或通知。官方依据 1
M12_STATIC_SITE
静态内容分发		CloudFront 使用 OAC 访问私有 S3 桶源，不能用 S3 网站端点代替。OAC 限制源访问，不提供访客身份验证；还需 HTTPS、缓存策略与更新失效策略。官方依据 1
M13_IMAGE_TAGS
图片自动标签		借鉴官方批量识别示例，改为 ObjectCreated 事件触发；Lambda 调用 DetectLabels 后 PutObjectTagging 写回。每对象最多 10 个标签，写入替换整组标签；应用需筛选标签并合并需保留的旧标签。仅监听创建事件以避免标签写入形成触发循环。官方依据 1 官方依据 2 官方依据 3
