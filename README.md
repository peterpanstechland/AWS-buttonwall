## 构建界面与垮塌规则（2026-10-14）

HMI 进入构建场景后，以业务入口、能力节点、分支连线和业务输出组成架构画布。
实体按键经过后端判定后点亮对应的角色实例；连线两端及其必要上游均接通后，数据流才开始流动。
M07 的两只 Lambda 分别代表入队和消费角色，不会因同一实体键亮起而一起完成。
CloudWatch、Cognito 等辅助关系独立显示。构建页保留 Kiro 玩法提示；模式、场景和设置页显示只读的 4×4 实体按键映射图，语言通过实体设置键切换。

按本次玩法要求，引导与竞速启用三个垮塌条件：拍错服务、单步超过 10 秒、整局 60 秒结束且当前架构未完成。
配置在 `config/game_config.json` 的 `collapse` 中；单步限时可调整或设为 0 关闭。
自由构建允许试选、撤销和添加实例，不对探索中的未完成组合判错；分析后可查看不同候选架构。
引导暂停冻结单步计时，可选角色不延长单步预算。整局超时仍先等待 MCU 的输入排空屏障，截止前的有效按击不会被动画丢弃。

垮塌终止本局，保留此前完成数、得分和既有错误扣分。它属于有效游戏结果（`final_state=VALID`），
由快照中的 `failure` 和 `graph.status=collapsed` 区分；设备故障仍为 `INTERRUPTED`。
新规则标记为 `rules-v1.3-collapse`，垮塌参数参与赛题包 hash，与旧规则榜单隔离。模拟器永远不进入正式榜。
这些变更覆盖 V1.2 规格中“拍错后可继续”等旧行为，原有计分分值和 MCU 帧格式保持兼容。

`config/solutions.json` 是角色与激活依赖；`config/workflows.json` 是可编辑的教学能力流、坐标和连线标签。
图中箭头表示能力交接，不表示实际部署的 AWS 网络拓扑；返回路径被简化，标有 ¹ 的结果交接由业务编排负责。
图标随 HMI 本地打包，来源与 SHA-256 记录在 `hmi/icons/manifest.json`。全部 16 个云服务使用 AWS 官方图标包中的原始 SVG，包括 EC2 和 IoT Core；首页、菜单、游戏架构和鼠标测试面板保持一致。
界面无远程字体、CDN 或云请求，支持中英文、暂停流动和减少动态效果。

## 7–10 寸横屏与 Kiro 交互

视觉主题对应活动的 [Bridge with Signal / Signal Hunt](https://2026-autumn-events.awscommunityday.cn/signal_hunt.html)：
明黄 `#ffd900`、米白 `#fff9e3`、黑 `#141414`、蓝 `#2b5ce6`、紫 `#6c3fd4`。
`hmi/signal.css` 管理活动配色；待机页以本地 SVG/CSS 演示实际 4×4 按钮墙和架构屏幕，shader 负责构建时的信号波、节点脉冲与链路粒子。
按钮墙作为“架构构建站”，用服务能力构成信号桥；图中数量与结果仅属于本局架构。
活动网页的 8 个 NFC 打卡点仍由活动系统管理，这里尚未接入 NFC 打卡、领取或完成状态。
固定顶栏使用用户提供的亚马逊云科技深色 logo 和 Kiro SVG；Kiro 主控键也使用原始图标。
品牌素材保存在 `hmi/branding/`，原文件校验记录在该目录的 `manifest.json`。
PNG 自带上下透明留白，仅通过 CSS 取景显示实际标志，保留原始像素、比例和颜色；浅色版本一并保留。

主布局按 1280×800 横屏设计：架构占据画面主体，底部显示下一项能力、单步倒计时和 Kiro 操作提示。
待机主视觉明确显示“点击 Kiro 按键，开始游戏”，所有用户提示均使用 Kiro 名称。16 个服务面板与独立 Kiro 面板均按 200×200 的正方形比例绘制，随屏幕缩放。开始后同一 Kiro 控件回到底部。
现场仅依赖实体按键：16 个服务键在菜单中负责选择，在游戏中负责答题；第 17 个 Kiro 键负责确认与返回。Kiro 的协议 ID 仍为 0，不改变接线映射。当前手势约定：

- 待机：Kiro 单击进入模式，长按 2 秒或按 D4 进入设置。
- 模式／场景：按亮灯服务键选择，Kiro 单击确认；双击兼容同一次确认。C3 或长按 Kiro 返回，D4 进入设置。
- 引导：单击暂停／继续，长按返回模式。成功后单击下一关；失败后单击重试；双击回模式；长按回待机。
- 竞速：长按提出结束，双击确认、单击取消；确认期间比赛时钟继续。
- 自由编辑：单击分析，双击撤销上一次服务操作，长按返回模式。
- 自由分析：单击切换候选，双击确认完整方案，长按继续编辑；拍服务键也会返回编辑。
- 自由构建中重复拍 Lambda 按实例数循环 `0 → 1 → 2 → 0`，无需额外增加实例按钮。

本机用空格／回车或屏幕 Kiro 模拟按下和松开，由虚拟 MCU 的去抖及手势分类器判定。
鼠标输入为每个电平保留至少 45ms，保证快速点击仍经过 20ms 去抖；双击窗口为 300ms，长按为 2 秒。
正常页面不显示触屏语言、静音、重听和回首页按钮，均通过实体设置键操作。语言、语音、音量和减少动态保存在 SQLite `ui_preferences`，重启、刷新及不同浏览器均读取设备设置。DEMO 页面默认显示“测试按键”，也可按反引号打开测试面板；`?debug=1` 额外显示维护调试控件。

| 界面 | 实体服务键映射 | Kiro（第 17 键） |
| --- | --- | --- |
| 模式 | A1／EC2 引导，A2／S3 竞速，B1／API Gateway 自由；C3 返回首页，D4 设置 | 单击确认，长按回首页 |
| 场景 | 前两排 A1、A2、B1、B2、A3、A4、B3、B4 对应 01–08 场景；C3 返回模式，D4 设置 | 单击开始，长按返回模式 |
| 设置 | A1 中文，A2 English，A3 音量减 20，A4 音量加 20，B1 语音开关，B2 重听说明，B3 减少动态，C3 返回，D4 首页 | 单击或长按返回上一页 |
| 结果／中断 | C3 首页，D4 设置 | 沿用重试／下一关、双击模式、长按首页 |

模式和场景键仅预选，必须按 Kiro 确认后才进入下一步。游戏中的 16 个服务键保持服务含义，不会因按到 D4 或 C3 意外进入设置或退出。竞速仍需长按 Kiro 后双击确认结束。

蓝色呼吸表示可选择，黄色脉冲表示当前选项，紫色常亮表示设置，白色常亮表示返回，无效键熄灭。屏幕按同一后端 `navigation` 映射显示位置、服务图案、动作和灯色，不能只依靠颜色辨认。Snapshot 的 `light_plan` 提供全 16 键灯效计划及亮度上限；当前 `hardware_applied=false`，尚未下发到 ESP。Kiro 实物为紫色面板，其按钮灯在硬件上常亮，不假设具备 RGB 控制。

## 自助引导与离线语音

当前 DEMO 页面支持鼠标测试：直接点击模式／场景／设置的亮灯方块；游戏时点击顶栏“测试按键”打开按真实位置排列的 4×4 服务键面板。面板不会遮住底部 Kiro，可用鼠标单击、双击或按住 Kiro 2 秒完成导航。所有点击走原有模拟按键事件，保留计时和判题规则；真实设备模式不开放这些模拟入口。

页面使用 `google notranslate` 和 `translate="no"` 避免浏览器自动翻译干扰双语界面。专用 RDK Chromium 另安装 `deploy/chromium-policy.json` 到 `/etc/chromium/policies/managed/aws-wall.json`，以 `TranslateEnabled=false` 禁用浏览器翻译提示。旧的 `--disable-translate` 参数已移除。

首页按真实槽位演示“按紫色 Kiro 开始 → 拍云服务按钮 → 架构逐步接通”，示例为 S3、Lambda、Rekognition、DynamoDB。动画只用于说明玩法，不改变后端状态。支持中英文、隐藏页暂停和减少动态时的静态三步说明。

模式／场景页先显示三步玩法；各状态底部持续显示当前任务，以及单击、双击、长按 2 秒和实体服务键的用途。提示明确使用 EC2、S3、API Gateway 等服务名称，开始键称为 Kiro。引导游戏逐步播报当前亮灯目标服务；竞速不播报答案。语音随状态和语言切换，不排队叠播，可通过设置键静音、调整播放音量或重听。待机每 60 秒、模式每 20 秒、场景每 30 秒温和提醒。

88 段中英文 MP3 随 `hmi/audio/` 部署，播放不联网。文案在 `prompts.json`；运行 `python -m pip install edge-tts mutagen` 后用 `python tools/generate_edge_voice.py` 重新制作。制作阶段使用 Edge TTS 在线合成，中文为 `zh-CN-XiaoxiaoNeural`，英文为 `en-US-JennyNeural`；生成报告记录音色、时长、速率和 SHA-256。文件全部生成并通过时长检查后才替换音频包。原 `generate_voice.ps1` 为旧版 SAPI 工具，不再用于当前语音包。

无人操作时，菜单／选关 90 秒、自由探索／引导暂停 120 秒、结果／中断页 30 秒自动回首页，最后 15 秒显示返回倒计时。阈值在 `config/game_config.json` 的 `inactivity` 中，设为 0 可关闭相应超时。后端独立计时，浏览器轮询不会续时；正在进行的竞速保持原有结束确认流程。

RDK kiosk 允许本地语音自动播放，通过 PulseAudio 输出；接入 USB 音箱后每 5 秒检查并优先切换该输出，保留用户音量。当前实际 USB 音箱尚未接入，音量和现场可听性需接入后确认。独立 HDMI 页面无触屏也可按原 Kiro／服务键完成游戏；实体按键接入仍取决于下述 MCU 协议实现。

`hmi/energy-field.js` 是本地 WebGL 1 shader：环境能量场、沿实际 SVG 曲线的流动粒子、节点光晕与激活波纹。
失败时粒子散落、节点倾斜下坠、链路熄灭。渲染最多 30fps，画布像素预算 70 万，限制点粒子尺寸；后台、暂停和减少动态效果时停止连续重绘。
无需额外 Three.js/p5.js 运行库；SVG 保留清晰文字与可访问结构，WebGL 不可用或上下文丢失时自动回退，恢复时重新创建资源。
可用 `?effects=off` 强制检查 SVG 路径。动态效果只反映后端状态，不参与玩法判定。

自动化测试覆盖三类垮塌、时间边界、重复角色、并行依赖、榜单隔离、九个场景的完成路径及 Kiro 电平手势导航。
本机浏览器验证不能替代 RDK X5 实测；板上 Chromium 帧率、串口及灯带联动仍需验证。

## 固件

ESP-IDF 5.4.4，目标 `esp32s3`。

```bash
. ~/esp/v5.4/esp-idf/export.sh
python3 tools/gen_hw_header.py
cd firmware
idf.py set-target esp32s3
idf.py build
```

当前固件做开机全灭、17 键去抖、四路 WS2815，并在串口上听逐口测试命令。控制台走原生 USB Serial/JTAG（开发板上枚举成 `USB 串行设备`，VID `303A`），不走 CH340。灯带数据仍在 GPIO1、2、41、40，不占用 USB 脚。

## 逐口测试

只有一套按键、灯带和按钮灯时，用电脑逐个插 16 个口。页面是观众视角的 4×4，和 `config/hardware.json` 的 `display_grid` 一致。引脚用这份 v0.8 网表，不沿用旧文档。

```bash
python3 tools/port_test.py
```

用浏览器打开弹出的页面。串口由这个程序打开，不走浏览器自己的串口窗口。下拉框里选开发板那个口（常见是 USB 串行设备，VID 303A）。点一个口：该组灯带前 32 颗跑马，这一口的按钮灯亮，页面提示按下按键。收到对应口才算通过；收到别的口会标出实际接到了哪里。

换插头前先关 12V。A2、B2、C2、D2 以及同组更后面的口，灯带数据从上一口的 DOUT 进来，原理图没有旁路跳帽。测这些口的灯带时，先断电把前面每个口的第 5 脚和第 7 脚短接。按键和按钮灯不经过这串数据。

固件要先烧录上面的 ESP-IDF 工程。串口命令是 `BW PING`、`BW SLOT A1`、`BW OFF`，应答以 `BW ` 开头。

### 2026-10-16 体验次数与探索示例

每次连续体验最多 3 局，开始即扣次数，失败和主动退出不返还；浏览器刷新、回首页、换模式、进入设置不补次数。第 3 局结果不再提供继续游戏，结束后显示换人页 5 秒，再迎接下一位。未满 3 局时，无操作超时结束本次体验并清空次数；没有身份识别，不保证同一自然人不能再次进入。重启后次数重新开始。

自由探索每局最多 120 秒；仅匹配服务种类及实例数量，不验证连接、IAM、区域可用性或部署正确性。候选给出缺失及未使用服务；全部键乱按不算完整。未收录组合不判错。引导默认从全部 13 个示例随机抽取，同次体验不重复；Bedrock 键选择随机，前两排保留 8 个指定场景。竞速固定 8 题顺序，保持同题包排名可比。

新增 M10–M13 为设备数据直存、异步任务入口、静态内容分发、图片自动标签。各方案的 AWS 官方文档链接与教学范围见 `config/solutions.json` 中的 `sources`、`teaching_points`，并配套 `config/workflows.json`。新例加入随机引导及自由探索，不改变竞速题包。中英文离线 Edge TTS 音频共 92 个。

方案完成后自动播放对应中英文 Edge TTS 离线解说，再播放操作提示。共 13 个方案、26 个解说 MP3，整个音频包共 118 个文件。竞速在结算页解说最后完成的方案，不打断计时；结果页 CloudFront 键可重播。带方案解说的结果页无操作等待 60 秒，切换页面会停止播放，第三次完成后仍先解说再提示换人。

自由探索所有 16 个服务键统一按 0 → 1 → 2 → 0 循环选数量，鼠标测试相同。双击 Kiro 撤销上一步。允许选择库中未使用的双实例组合，但不因此判定方案有效。中英文 free_edit 语音已同步。
